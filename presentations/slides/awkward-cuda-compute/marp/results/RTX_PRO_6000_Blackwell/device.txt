NVIDIA RTX PRO 6000 Blackwell Server Edition (GB202, compute capability 12.0 / sm_120), 98 GB.
Reproduced on a brev instance (female-maroon-roundworm), CUDA 13.2. Machine label: RTX_PRO_6000_Blackwell.

Blackwell (sm_120) required three fixes vs the RTX 6000 Ada stack:
  - nvidia-nvjitlink-cu13 : torch's cu128 wheel pulls an older cu12 nvjitlink (12.8) that
    cannot link sm_120 code -> cuda.compute custom ops failed with nvJitLink error 999 /
    "may need newer version". Installing the CUDA-13 nvjitlink fixed it.
  - cuda-cccl 1.1.0       : provides the serialize / make_* AoT API (1.0.1 lacked it).
  - numpy < 2.5           : cuda-cccl 1.1.0 pulls numpy 2.5, but numba needs <= 2.4.
Both reproduce.sh and reproduce_adl.sh now apply these automatically.
